Este portfolio pertenece a Aymar Salgado Dieguez. Para cualquier consulta relacionada con tus datos, puedes escribir a salgadodieguezaymar@gmail.com.

El asistente de contacto

Los campos se procesan en tu navegador para preparar un borrador. Esta web no almacena esos datos, no los envía a un servidor y no confirma ningún envío. Si eliges abrir Gmail o tu aplicación de correo, el nombre y el texto del proyecto se transfieren a ese servicio para que puedas revisarlos y enviarlos.

Si me escribes

Usaré la información que compartas para responder a tu consulta y, si corresponde, preparar una propuesta sobre el proyecto que solicitas. Se conservará durante la gestión de esa conversación y los plazos que puedan resultar aplicables si se inicia una relación profesional. Puedes solicitar acceso, rectificación o supresión escribiendo al mismo correo.
